So we need help of 'CAP Theorem' here :

CAP Theorem:

Consistency , Availability , Partition Tolerance

-Consistency : 
so when multiple servers are involved and client istrying to fetch the data so it is important the he gets the same data everytime.

-Availability :
whenever client is trying to get data he should get response, even if some nodes/servers are down

-Partition Tolerance :
s1 - s2 replicating data but suppose connection fails, so even if connection breaks b/w some nodes,  system should continue to operate.


so theorem basically says that in order to support 2 of these out of 3 , one should sacrifice.

so any of of below should support based on use case:
